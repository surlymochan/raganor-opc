# [v1] 数据加载与空状态

## 标题

`[v1] 简报数据加载器（用户目录 / demo / 空状态）`

## 描述

- 支持从 **环境变量或 CLI 参数** 指定数据根目录；未指定时默认 `examples/demo-data/`（或文档约定路径）  
- 解析日程、待办、OKR、习惯；解析失败时 **报错信息可读**（文件路径 + 字段）  
- **空状态**：无文件或空数组时，不向正文注入虚构事件；后续渲染阶段输出 **「无数据 / demo」** 提示  

## 验收标准

- [ ] 单测或脚本：demo 目录 → 结构化内存对象（或等价）  
- [ ] 空目录 → 不崩溃，标记 `hasData=false` 或等价  
- [ ] 文档：说明 `BRIEF_DATA_DIR`（或实际命名）
