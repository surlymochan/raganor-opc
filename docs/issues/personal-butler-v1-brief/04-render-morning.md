# [v1] 渲染：晨间简报 Markdown

## 标题

`[v1] 晨间简报 Markdown 渲染（六区块顺序）`

## 描述

按 `personal-butler.md` **§3.3** 顺序输出 **一级标题或固定 `##` 区块名**（便于快照测试），内容为中文：

1. 今日日程（含 **冲突/空档** 提示逻辑：重叠时段须标出）  
2. 待办 Top 3（不足 3 条则全列；按优先级/截止排序规则写进代码注释）  
3. 本周 OKR 进度（**一句话摘要** + 可选状态标签）  
4. 习惯（今日应完成 / 已完成）  
5. **股票（占位）** + **固定脚注**（非投资建议，§9 证券表述）  
6. **身心健康（占位）** + **固定脚注**（非医疗建议，§9 健康表述）  

数据缺失时：对应主列表下写 **「当前无数据（demo 模式）」** 或等价，**禁止编造**。

## 验收标准

- [ ] 对 `demo-data` 跑一次，stdout 含 6 个区块且顺序正确  
- [ ] 股票、健康区块 **均含** 免责声明关键词（如「不构成投资建议」「不提供医疗诊断」——可与 §9 原文对齐）
